Introdução
------------------------------------------------------------------------

Nossa batalha naval consiste em tabuleiros 10x10 tanto do player quanto do computador, onde a missão do jogador é derrubar todos os cinco navios do oponente. 

No início, o jogador decide onde inserir seus cinco navios que ocupam uma posição em seu próprio tabuleiro 10x10. Buscando deixá-los nas posições mais escondidas para o computador não derrubá-los. O computador também prepara seu tabuleiro aleatóriamente.

Agora, começa a sequência de ataques. O jogador decide a linha e a coluna para seu ataque, alternando com o computador, buscando atirar em todas as embarcações do oponente.

Se o jogador conseguir derrubar os navios do computador antes de ter os seus afundados, ele ganha o jogo.



Como configurar no seu computador:
------------------------------------------------------------------------

1. Este jogo foi feito no python. Instalar aqui: https://www.python.org/downloads/release/python-3146/

2. Baixe ou copie e cole o código no seu dispositivo

3. Rode 'python batalhaNavalFinal+extra.py' no terminal
