Introdução
------------------------------------------------------------------------

Nossa batalha naval consiste em tabuleiros 10x10 tanto do player quanto do computador, onde a missão do jogador é derrubar todas as frotas do oponente. 

No início, o jogador decide onde inserir seus meios aquáticos em seu próprio tabuleiro 10x10, eles são compostos por: Porta-aviões (ocupa 5 posições), Navio-tanque (ocupa 4 posições), Contratorpedeiro (ocupa 3 posições), Submarino (ocupando 2 posições) e Navio (ocupando 1 posição). buscando deixá-los nas posições mais escondidas para o computador não derrubá-las. O computador também prepara seu tabuleiro aleatóriamente.

Agora, começa a sequência de ataques. O jogador decide a linha e a coluna para seu ataque, alternando com o computador, buscando atirar todas as embarcações do oponente.

Se o jogador conseguir derrubar as frotas do computador antes de ter as suas afundadas, ele ganha o jogo.



Como configurar no seu computador:
------------------------------------------------------------------------

1. Este jogo foi feito no python. Instalar aqui: https://www.python.org/downloads/release/python-3146/

2. Baixe ou copie e cole o código no seu dispositivo

3. Rode 'python batalhaNavalFinal+extra.py' no terminal
